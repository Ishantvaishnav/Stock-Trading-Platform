# 📈 Stock Trading Simulation (Java)

A console-based stock trading simulator built using **Java** as a part of my **Java Programming**.
The application allows users to buy and sell stocks, manage their portfolio, and track transaction history while simulating real-time market price fluctuations.

---

## 🚀 Features

- Live stock market simulation
- Buy stocks
- Sell stocks
- Portfolio management
- Transaction history
- Dynamic stock price updates
- Cash balance management
- Multiple predefined stocks

## ⚙️ How It Works

1. The program loads default stocks.
2. User starts with an initial cash balance.
3. User can:
   - View Market
   - Buy Stocks
   - Sell Stocks
   - View Portfolio
   - View Transaction History
4. After every trade, market prices change randomly to simulate a real stock market.
